# Project Code of Conduct

ICESEE-Spack follows the ICESEE project's [Contributor Covenant Code of Conduct](ICESEE/CODE_OF_CONDUCT.md), including its standards, scope and enforcement contacts. It applies to this repository's issues, reviews, wiki and other project spaces.

Use the contact information in that policy for conduct concerns. Scientific and technical disagreements should be discussed respectfully and supported by evidence.
