Run subtree commands from the parent root. Publish parent branches to ICESEE-Spack and split ICESEE branches to ICESEE. Use explicit nonempty source refs for pushes.

The [October 16 PACE validation record](pace-validation-2026-10-16.md) is historical evidence, not a guarantee for every later checkout or scientific configuration.
